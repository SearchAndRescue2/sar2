Search And Rescue II documentation : the scenery editor in 10 short lessons.

Tip:
    On my computer and even if it is 'num locked', the numeric pad works as expected in SarII only when I press the [Shift] key. If not, it works as the direction keys.

  • Lesson 1: how to enter edit mode

    • Start Search And Rescue II then go to Free Flight.
    For these lessons, please choose the Test world theater and the CG Cutter location, select your favorite Aircraft, then Begin simulation.
    Once simulation loaded, press the slash ( [/] ) key on your keyboard, then type scnedit on as command name :

    Press the [Enter] key : you will see a 1m x 1m x 1m triedron. Red arrow (X axis) points right, green arrow (Y axis) points front, and blue arrow (Z axis) points up :

    The [EDIT MODE ON] red text at the top left corner of the SarII window confirms that editing mode is active.
    Note that all usual in-game keyboard commands remain available: [m] for map view, [F3] for spot view, [-] / [+] to zoom in/out, and so on...

    Once editor mode activated, if you want to activate the scenery editor Graphical User Interface, enter /gui on.
    If it is available (i.e. if SarII has been compiled with it), and if SarII is in windowed mode (set game Options->Graphics->Fullscreen switch to OFF), you will see something like this:
    Note that even if GUI can't be activated in full screen mode, it will perfectly work in windowed mode if the SarII window is maximized.

    As the GUI may be unavailable, hereunder lessons shows the scenery editor "text command" version. If you've activated the GUI, you just have to click on the buttons instead of typing the commands on keyboard.


  • Lesson 2: how to move the triedron

    • Use your joystick to move and rotate the triedron on the horizontal plane, and use the joystick throttle axis to move it up or down.
    If the triedron seems to move up or down by itself, it is certainly because your joystick throttle is not centered.

    Look on screen at the right of the altitude value: if you see a + (plus) sign, it means that altitude increases. If you see a - (minus) sign, it means that altitude decreases. And if you see an = (equal) sign, it means that altitude don't change. Putting the throttle at a low position is a good solution to always touch the ground. You can too press the [Home] or [End] keyboard keys to move the triedron up or down by 25ft (~7.62m) steps.

    Note that you can't move under ground.


  • Lesson 3: how to get information about an object

    • Move the triedron near the middle of the CG Cutter helipad, then type /info and press the [Enter] key. Note that the information window title bar gives you the object 'internal' number and the distance between the triedron origin and the object origin :

    You can obtain information about the 5 closest objects by entering /info next instead of /info.

  • Lesson 10: how to quit editor mode

    • Two solutions:

    • First, if you don't want to fly on your modified scenery right now, just press the [ESC] key, answer [y], and press [Enter] to go back to menu.

    • Second, if you want to fly on your modified scenery, you can enter /scnedit off to return to the Free flight mode:

    Tip: pay attention to move the triedron far away of any object before entering /scnedit off: if your helicopter touches some dangerous object, it will certainly immediately explode!

  • Annex: available commands list

    • Don't forget to press the [/] key to enter command mode before entering any command name.

    Editor management :

    scnedit on : Activate scenery editor mode.
    gui on : Enable the scenery editor Graphical User Interface (if available). Note that once you exit the GUI, it cannot be re-enabled in the same SarII game session 😞 : you will have to quit then restart SarII.
    scnedit off : Shut off editor mode and return to normal mode.
    print : Print scenery changes to a $HOME/sar2_editor_report_YYYYMMDDHHMMSS.txt text file.

    Object creation :

    create_fire ... or cfi ... or create fire ... : Create a fire. See create_fire for the ... parameters list.
    create_helipad ... or che ... or create helipad ... : Create a helipad. See create_helipad for the ... parameters list.
    create_human ... or chu ... or create human ... : Create a human. See create_human for the ... parameters list.
    create_premodeled ... or cpr ... or create premodeled ... : Create a premodeled object. See create_premodeled for the ... parameters list.
    create_runway ... or cru ... or create runway ... : Create a runway. See create_runway for the ... parameters list.
    create_smoke ... or csm ... or create smoke ... : Create a smoke trail. See create_smoke for the ... parameters list.
    load_object ... or lob ... or load object ... : Load a V3D (*.3d) model from disk. See model_file for the ... parameter.

    Closer object actions :

    move or mv : Get the closer object as current object in order to move it with the joystick.
    move_at or mva or move at : Move the closer object by modifying its position and orientation values.
    modify or mod : Modify the closer object parameters. Tip: you can enter modify obj_num or mod obj_num to modify the object which has for number obj_num rather than modifying the closer object.
    info : Give information about the closer object.
    info next or ifn : Give information about the ‘next’ closer object.
    remove or rm or delete or del: Remove (delete) the closer object. Warning: there is no confirmation dialog and no "undo" function!
    copy or cp : Copy the closer object as current object.
    name : set or modify the name of the closer object. Have a look at object_name for what for the object name is and how it can be used.

    Current object actions :

    set : Set the current object to scenery.
    unload or ul : Unload the current object (let the triedron alone).
