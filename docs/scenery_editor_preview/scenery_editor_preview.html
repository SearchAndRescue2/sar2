Search And Rescue II documentation :
scenery editor preview in 10 short lessons.

General notes:
    This is a preview: this editor is maybe (certainly?) buggy, and features can change.
    Tip: on my computer and even if it is 'num locked', the numeric pad works as expected in Sar2 only when I press the [Shift] key. If not, it works as the direction keys.

  • Lesson 1: how to enter edit mode

    • Download the scenery_editor_preview branch, compile it (scons) -you don't need to install it-, then start Sar2 from command line (./sar2.sh) and go to Free Flight.
    Choose the Test world theater and the CG Cutter location, then go to the Aircraft choice.
    Choose the Object placer aircraft, then Begin simulation.
    Once simulation loaded, press the slash ( [/] ) key on your keyboard then type scnedit on as command name :

    Press the [Enter] key : you should see a 1m x 1m x 1m triedron. Red arrow (X axis) points right, green arrow (Y axis) points front, and blue arrow (Z axis) points up :

    The [EDIT MODE ON] red text at the top left corner of the screen confirm that editing mode is active.
    Note that all usual SarII keyboard commands remain available: [m] for map view, [F3] for spot view, [-] / [+] to zoom in/out, and so on...


  • Lesson 2: how to move the triedron

    • Use your joystick to move and rotate the triedron on the horizontal plane, press [Home] or [End] keys to move it up or down (25ft ~ 7.62m step). Note that you can't move under ground.


  • Lesson 3: how to get information about an object

    • Move the triedron near the middle of the CG Cutter helipad, then type /info and press the [Enter] key. Note that the information window title bar gives you the object 'internal' number and the distance between the triedron center and the object center :

    You can obtain information about the 5 closest objects by typing /info next instead of /info.


  • Lesson 4: how to modify an object

    • Stay in the middle of the CG Cutter helipad and rotate the triedron 90° to left in order to see the USCG text painted on the helipad ground.
    Now, type /modify and press [Enter], then replace the USCG text by Hello_World!. Don't forget the underscore character between 'Hello' and 'World!' :

    Press [Enter] to validate your modification :


  • Lesson 5: how to move an object

    • Rotate the triedron 90° right then go near the human with the white pant (remember, you can move up or down by pressing [Home] or [End] keys). Once close to the human, type /mv (or /move)

    Then, press [Enter]. The human is now 'sticked' to the triedron: move him in front of the turquoise cap boy (hurry up, he needs help!), then enter /set to place the human at his new position :


  • Lesson 6: how to copy an object

    • Move the triedron near the jetski, then enter /cp (or /copy) to copy the jetski. Move the copied jetski to the right of the first one, then enter /set. Note that the copied jetski is always sticked to the triedron: move it a little bit to right, then /set it an other time, then set it a third time :

    Ok, that's funny, but the jetski is really... sticky! Hopefully, we can 'unstick' it with the /ul (or /unload) command :


  • Lesson 7: how to remove an object

    • Move the triedron near the first left jetski, then, enter /rm (or /remove) :


  • Lesson 8: how to create or load a new object

    • Let's begin by entering /cfi 0.5 5.0 (or /create_fire 0.5 5.0). Well done! You have created a 0.5m radius and 5.0ft tall fire :

    Set (/set) a fire at the rear of each jetski, then unload the fire :

    Now, let's try with a *.3d model which is stored on disk: enter /lob automobiles/cuda.3d (or /load_object automobiles/cuda.3d), then set and unload it.
    Note that characters case is important: for example /lob automobiles/cuda.3D will not work.

  • Lesson 10: how to quit cleanly editor mode

    • /scnedit off

    Note that it is very important to quit editor mode cleanly, because if not, scenery editor memory will NOT be freed until you reboot your computer! :

    Then, press the [ESC] key, answer [y], and press [Enter] to go back to menu.


  • Annex: available commands list

    • Don't forget to press the [/] key to enter command mode before entering any command name.

    Editor management :

    scnedit on : Activate scenery editor mode.
    scnedit off : Shut off editor mode and return to game mode.
    print : Print scenery changes to console.

    Object creation :

    create_fire ... or cfi ... or create fire ... : Create a fire. See create_fire for the ... parameters list.
    create_helipad ... or che ... or create helipad ... : Create a helipad. See create_helipad for the ... parameters list.
    create_human ... or chu ... or create human ... : Create a human. See create_human for the ... parameters list.
    create_premodeled ... or cpr ... or create premodeled ... : Create a premodeled object. See create_premodeled for the ... parameters list.
    create_runway ... or cru ... or create runway ... : Create a runway. See create_runway for the ... parameters list.
    create_smoke ... or csm ... or create smoke ... : Create a smoke trail. See create_smoke for the ... parameters list.
    load_object ... or lob ... or load object ... : Load a V3D (*.3d) model from disk. See model_file for the ... parameter.

    Closer object actions :

    move or mv : Get the closer object as current object in order to move it.
    modify or mod : Modify the closer object parameters.
    info : Give information about the closer object.
    info next or ifn : Give information about the ‘next’ closer object.
    remove or rm or delete or del: Remove (delete) the closer object.
    copy or cp : Copy the closer object as current object.

    Current object actions :

    set : Set the current object to scenery.
    set_to_ground or stg : Set the current object to ground even if don't touch it. Useful for helipads and runways because they can't be moved down by pressing the [End] key.
    unload or ul : Unload the current object (let the triedron alone).
